# Changelog

## 2.1.0 (2026-11-17)

Existing patterns catch more forms of the same habits. The count stays at 56.

- Workflow step 6 now looks for the habit that replaced the one removed, such as comma splices
  where the em dashes were.
- AI vocabulary (16) adds virtue words a text applies to itself. Filler (17) adds adjectives
  that grade the reader's task. Hedging (18) adds vague quantifiers where a figure belongs.
- Copula avoidance (19) adds spec-sheet verbs. Negative parallelisms (20) adds the contrast
  frame rebuilt with "rather than". False agency (25) adds software given bodily actions.
- Fragmentation (28) adds fragment and numeral headings. Signposting (37) adds recap openers.
  Templated structure (41) adds the stock origin story and values as bare nouns. Placeholders
  (55) adds stock sample names.
- New material is adapted from Vercel's writing guidelines and taste-skill, credited in the
  README and LICENSE.

## 2.0.0 (2026-11-14)

Renamed from humanizer to ai-copyedit.

- The skill, the plugin, and the repository are now named `ai-copyedit`, and the marketplace is
  `wolfurx-ai-copyedit`. The old repository address redirects to the new one.
- The rules and patterns are the same as in 1.0.0.
- If you installed the skill as `humanizer`, remove that copy and install `ai-copyedit`. The
  README has the commands.

## 1.0.0 (2026-11-14)

First public release.

- 56 patterns, each with a before and after example whose "after" uses only facts from its
  "before".
- Safeguards: text is treated as material rather than instructions, evidence strength decides
  when a tell justifies an edit, detect mode does not treat second-language English or short
  samples as evidence, and the never-inject rules forbid invented experiences, facts, promises,
  and detector tricks.
- Native writing in any language, with guidance on translated-sounding text and on which English
  rules change elsewhere.
- Install paths for Claude Code (plugin), the Skills CLI (about 80 agents), Claude.ai, and
  manual copy.
